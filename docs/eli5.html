組合役員アプリ絵本

毎日の「やること」を、
ひとつにまとめるアプリです。

組合の役員が、タスクや予定を忘れずにこなすための道具です。絵でざっくり紹介します。

下にスクロールして、ページをめくってください
Page 01 だれが使うの？

組合の役員さんが使います。

委員長や書記長など、自分の役職に必要な情報だけが届くようになっています。

委員長 書記長 会計 執行委員
Page 02 なにができるの？

6つのことが、これ1つで。

タスク管理

組合員対応も事務も、リストでひと目

カレンダー

会議や出張の予定をまとめて確認

メモ・音声

思いついたことを文字でも声でも

旅費精算

出張の交通費をその場で計算

役職フィルタ

自分に関係ある予定だけに絞り込み

クラウド同期

スマホとパソコンでデータを共有

Page 03 タスク管理

やることを、忘れない。

終わったものにはチェック。組合員対応の進み具合も数字でわかります。

Page 04 カレンダー

予定を、うっかりしない。

会議や出張を一目で確認。自分の役職に関係あるものだけ絞り込めます。

Page 05 メモ・旅費精算

思いついたら、すぐ記録。

文字でも声でもメモできて、出張の交通費もその場で計算できます。

Page 06 クラウド同期

スマホでも、パソコンでも。

Googleドライブでつながっているので、どちらで入力しても、もう片方にちゃんと反映されます。

Page 07 まとめ

組合の毎日を、ちょっとラクに。

6つの機能が1つのアプリにまとまっているだけ。むずかしい操作は、ひとつもありません。
